# BestPick

BestPick is a smart comparison platform that helps users compare ride prices, travel time, and recommendations across multiple providers.

## Tech Stack

- TurboRepo
- Next.js
- React
- React Native (Expo)
- Node.js
- Express
- MongoDB Atlas
- Redis
- BullMQ
- TypeScript

## Branches

- main → Production
- develop → Development

## Development Workflow

Feature Branch → Pull Request → develop → main
